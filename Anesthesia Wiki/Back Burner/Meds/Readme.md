## How to Update
1. Open a drug file.
2. Update the relevant indication block only (do not mix doses across indications).
3. Update Last updated date in Quick Facts.
4. Keep global sections (warnings, interactions, monitoring) current.

## Suggested Rule
- If an indication has meaningfully different dosing or monitoring, it must have its own subsection under "Indication-Specific Guidance".
